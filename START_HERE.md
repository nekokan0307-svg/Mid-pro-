# FITBEAT integrated revision (English interface)

This ZIP is intended for a **new GitHub Pages repository**. Upload the contents of this folder to repository root; keep folder names. GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).

Integrated changes: recovered original-style white Bichon mascot illustration; improved contrast for level cards and setup; responsive two-lane note layout; revised results layout with score, accuracy, perfect/good/miss, max combo, estimated calories and Home/Retry; visible Exit button; English instructions and Twist & Punch cues; existing camera and phone connection code preserved.

**Not verified**: real-world webcam pose recognition, iPhone motion permissions, live pairing, timing/scoring on devices. The 7 stage background images currently remain earlier neon scene artwork, not the fully approved landscape scenes; original exact background assets were not available as individual files. Do not describe this as a finished exact visual match.

Estimated calories use MET * 3.5 * body weight (kg) / 200 * duration (minutes); these are rough estimates, not sensor-measured energy expenditure.
